# 随包字体资源

本目录仅包含青年新语公文所需的五款字体：方正小标宋简体、仿宋_GB2312、楷体_GB2312、黑体、Times New Roman。原文件内容未修改；英文文件名用于稳定引用。角色、相对文件名及 SHA256 见 manifest.json。

来源：浙江师范大学外国语学院《常用办公字体（字库）》
https://flc.zjnu.edu.cn/2024/1110/c18580a485306/page.htm

原下载附件：

获取日期：2026-10-28。

来源页面提示部分字体仅供非商业用途，商业用途需联系字体厂商获取授权。高校公开下载不等于开源许可或无限制再分发授权；本 skill 不授予额外字体权利，使用者须确认适用授权。

使用方法：严格执行 SKILL.md Step 3，在当前 skill 根目录校验哈希并生成 work/fonts.json，然后在实际渲染主机安装同一批字体。不得将旧工作区的绝对路径直接移植到其他主机。

不得重命名字体内部家族、改用近似字体或因缺字擅自换成 GBK 版本；缺字仍须按现有门禁停止。附带字体不表示任何内容或版式补充规则已经取得用户确认。
